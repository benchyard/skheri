# Contributing

Keep Skheri small: portable charts, executable examples and an agent-readable
contract. Open an issue before introducing a controller, provider dependency or
new configuration language. Document whether a feature works today or is proposed.

Run the README validation commands. Add integration coverage when changing volume
lifecycle, preview routing, or application rollout behavior. Never run acceptance
tests against a shared or production cluster.

Contributions are licensed under Apache-2.0. Do not include credentials, customer
configurations, screenshots of private data, or internal endpoints in examples.
